# Tastenkürzel

Die wichtigsten Funktionen sind per Tastatur erreichbar. Eigene Kürzel legen Sie an Dashboard-Knöpfen fest.

| Kürzel | Wirkung |
|---|---|
| F1 | Hilfe zur aktuellen Ansicht |
| Shift+? | Übersicht der Tastenkürzel |
| Strg+K | Hilfe durchsuchen |
| Alt+1 … Alt+9 | Ansichten wechseln (Reihenfolge der Navigation) |
| Strg+Enter | Anfrage senden (UDS senden) bzw. Aktion ausführen |
| Leertaste | Trace pausieren/fortsetzen (wenn kein Eingabefeld aktiv ist) |
| Esc | Dialog oder Hilfe schließen |
| eigene Kürzel | an Dashboard-Knöpfen festgelegt |
