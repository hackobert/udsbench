# Hinweis zur Entstehung / AI disclosure

**Deutsch.** udsbench wurde **vollständig von einer KI erstellt**: Architektur, Quellcode (Backend
und Frontend), Tests, Konfigurationsbeispiele, Hilfetexte und Dokumentation wurden von Claude
(Anthropic) in Claude Code generiert. Grundlage war eine fachliche Aufgabenbeschreibung des
Maintainers, der Anforderungen vorgegeben, Ergebnisse geprüft und Folgeaufträge erteilt hat, den
Code aber nicht selbst geschrieben hat.

Was das für Sie bedeutet:

* Der Code ist durch automatisierte Tests abgesichert (u. a. eine Konformitäts-Suite für
  ISO 15765-2 und ISO 14229 gegen ein simuliertes Steuergerät), wurde aber **nicht** durch eine
  unabhängige Stelle zertifiziert oder von Menschen Zeile für Zeile geprüft.
* Behandeln Sie udsbench wie jede andere frühe Open-Source-Software: Ergebnisse gegen
  Spezifikation und Live-Trace prüfen, zuerst am virtuellen Bus und Prüfstand testen.
* Beiträge, Reviews und Fehlerberichte von Menschen sind ausdrücklich willkommen.

**English.** udsbench was **entirely generated by AI**: architecture, source code (backend and
frontend), tests, example configurations, help texts and documentation were produced by Claude
(Anthropic) in Claude Code, based on a domain specification written by the maintainer, who defined
requirements, reviewed results and requested changes but did not write the code. The code is covered
by automated tests, including a conformance suite against a simulated ECU, but has not been
independently certified or fully reviewed by humans. Please verify results before relying on them.
